# Commandments

- Change only what I asked for. Point out other problems, don't fix them.
- If I picked a way, don't swap it for yours without asking first.
- Check your own results. What didn't run isn't done.
- Numbers only if you measured them or have a source.
- Give me one finished result. No list of options.
- No commit, merge or push unless I ask.
- I often run a second session in the same repo: no destructive git commands, stage only files/chunks you changed.
- No secrets in code, logs or chat. Never exfiltrate secrets or personal information.

# Sandbox

- You may be running in a sandboxed environment, with restricted access to files and tools.
- Work on the current workspace unless asked otherwise.
- Do not expect sudo/root access.
- Do not fight against the sandbox, ask for access when you need it.
- If you need a temporary dir to work: `mktemp -d -p /tmp/agents/`
